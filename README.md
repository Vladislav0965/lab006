# lab006
1. positions.py — индексы максимума
Что делает:
Считывает список a.
Если список пуст — выводит 'Нет данных'.
Иначе строит список b всех индексов, где значение равно максимуму: enumerate(a) даёт пары (индекс, значение), условие f == max(a) отбирает нужные, i — индекс.
Проверки:
Пустой список обрабатывается отдельно (иначе max(a) на пустом списке даст ошибку).
max(a) вычисляется заново на каждой итерации — неэффективно, но корректно.
Результат (при корректном вводе): для a = [3, 7, 7, 2] → b = [1, 2]. Для пустого — сначала 'Нет данных', затем ошибка.

2. statistics.py — статистика списка
Что делает: считает количество, сумму, максимум, минимум и среднее (с двумя знаками).
Проверки:
Пустой список → 'Нет чисел'.
Максимум ищется вручную циклом (b — текущий максимум), минимум — аналогично (c — текущий минимум).
Результат: для a = [4, -2, 9, 1] → 4 12 9 -2 3.00. Для всех отрицательных — максимум будет неверно равен 0.

3. transform.py — модули элементов
Что делает: считывает список, печатает его, затем построчно печатает модуль каждого элемента (abs).
Проверки: нет — пустой список просто даст пустой вывод, ошибок не будет.
Результат: для a = [-3, 5, 0] → печать [-3, 5, 0], затем 3, 5, 0 на отдельных строках.

4. variant.py — сортировка и подсчёт чисел ≥ 10
Что делает: считывает список, печатает исходный, сортирует по возрастанию (sort() на месте), затем считает количество (k) и сумму (sm) элементов, больших или равных 10.
Проверки:
Условие i >= 10 — граница включительная (10 учитывается).
Пустой список не ломает программу: цикл не выполнится, выведется [] 0 0.
Результат: для a = [12, 3, 10, 25] → печать [12, 3, 10, 25], затем [3, 10, 12, 25] 3 47 (числа ≥ 10: 10, 12, 25; их сумма 47).
